TripMaster

Itinerary planner/tracker mobile App

Overview

TripMaster is a centralized travel management application designed to organize itineraries and finances into a clean, card-based dashboard. It allows users to track current activities, such as hotel check-ins, while monitoring a dynamic "Total Trip Budget" via a live progress bar.

The Goal: The primary goal is to reduce travel-related stress by combining schedule tracking and financial management in one place. By providing a clear roadmap of both time-sensitive plans and remaining funds, the app helps travelers stay organized.

Process

I began by architecting a scalable data model for itinerary items, followed by building the core dashboard logic. A critical phase involved developing the AddItem component with a callback system to ensure seamless data synchronization.

Key Takeaway

I learned the importance of state synchronization. By building a functional budget tracker, I discovered that user trust is built through immediate UI feedback and instant state updates.
